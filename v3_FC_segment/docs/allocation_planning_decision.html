MIDDLE FC→DC 位置选取规则对照
Rule条件逻辑目的
Rule 1 无保质期要求 + 多 location 找最接近 excess qty 的单个 location；若误差 >15% 则从小到大累积 尽量整 location 操作，减少拆 lot
Rule 2 无保质期要求 + 单 location 只转 excess qty，FC 保留 adl×30D 最小化操作量，不动用整个 location
Rule 3 need_minimal_exp=1 + 多 location 按 exp_date 降序，最远日期先移出，累积到 excess FC 保留最近到期批次，FEFO 最优
Rule 4 need_minimal_exp=1 + 单 location 只转 excess qty，FC 保留最近批次 保质期敏感 SKU 的 excess-only 移出
