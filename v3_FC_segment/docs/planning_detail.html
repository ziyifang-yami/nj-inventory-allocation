2 · Step A — DC→FC (Demand Side, executed first each day)
flowchart TD A([Day d starts]) --> B[effective_cap_in = cap_in\nfixed daily capacity] B --> C{TOP pending?\nidx_in1 < n_in1} C -->|Yes| D[Take next TOP SKU from in_t1\nsorted d2s ASC] D --> E{pallet capacity\ncheck ok?} E -->|Yes| F[Add TOP SKU to today's DC→FC batch\ns3 += 1, day_vol_in += vol] E -->|No, pallet full| G[Skip SKU, advance j] F --> H{s3 < cap_in?} H -->|Yes, more capacity| C H -->|No, cap reached| I C -->|No, TOP done| I[Fill remaining cap with MIDDLE\nfrom in_t2, sorted by priority] I --> J{MIDDLE pending?\nidx_in2 < n_in2} J -->|Yes| K{s3 + s4 < cap_in?} K -->|Yes| L[Take next MIDDLE SKU\nsorted: d2s×1e6 − vol×1e3 − adl] L --> M{pallet capacity ok?} M -->|Yes| N[Add MIDDLE to batch\ns4 += 1, day_vol_in += vol] M -->|No| O[Skip, advance j] N --> J K -->|No, cap reached| P J -->|No more MIDDLE| P P([DC→FC batch finalized\ns3 TOP + s4 MIDDLE\nday_vol_in, day_locs_in])
3 · Step B — FC→DC (Supply Side, greedy balance)
flowchart TD A([DC→FC batch known\nday_vol_in, day_locs_in]) --> B[need_vol = day_vol_in\nneed_locs = day_locs_in\nMust release at least this much] B --> C{s1+s2 < cap_out?} C -->|Yes, more capacity| D{cum_out < need_vol\nOR cum_locs < need_locs?\n= still need to balance} D -->|Yes, balance needed| E{next_mid_vol ≥ next_tail_vol\nAND MIDDLE available?} E -->|Yes, MIDDLE bigger| F[Take MIDDLE SKU from out_t2\n= greedy: bigger vol releases more space] E -->|No, TAIL bigger or no MIDDLE| G[Take TAIL SKU from out_t1\n= always prefer TAIL] D -->|No, balance satisfied| H{TAIL available?\ntail_ptr < n_out1} H -->|Yes| I[Take TAIL SKU\nfill remaining cap with TAIL] H -->|No, TAIL exhausted| J{MIDDLE available?\nmid_ptr < n_out2} J -->|Yes| K[Take MIDDLE SKU\nfill with MIDDLE only] J -->|No| L[Break — nothing left] F --> M[cum_out += vol\ncum_locs += 1] G --> M I --> M K --> M M --> C C -->|No, cap reached| N N([FC→DC batch finalized\ns1 TAIL + s2 MIDDLE\nday_vol_out, day_locs_out]) N --> O[Re-sort today's FC→DC by vol DESC\nfor operational efficiency on floor]
4 · Cumulative Tracking & Day Completion
flowchart TD A([Today's batches finalized]) --> B[Update cumulative counters\ncum_vol_out += day_vol_out\ncum_locs_out += s_out\ncum_sku_in += s3 + s4\ncum_vol_in += day_vol_in] B --> C[Record to df_sched\nitem_number, seg, action\ntransfer_qty, transfer_vol\nday, date, pallets] C --> D{All 4 lists exhausted?\nidx_out1≥n_out1 AND idx_out2≥n_out2\nAND idx_in1≥n_in1 AND idx_in2≥n_in2} D -->|Yes| E([Loop ends]) D -->|No| F{day < plan_days?} F -->|Yes| G([Next day]) F -->|No, window exceeded| E E --> H[Compute summary\npct_in, pct_out, vol_balance\nlocs_freed, locs_consumed\nswap_log per day]
