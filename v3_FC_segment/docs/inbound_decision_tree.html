保质期情形 × 收货推荐 × Planning 联动
情形 日期排序 收货推荐 Planning 联动动作
1.1 FC Bin exp > DC exp DC 无额外动作，正常消化 DC 旧货
1.2 FC Bin exp < DC exp DC 加速 FC Bin→DC，标记 FC Bin SKU 优先清出
2.1 FC Stock exp > DC exp DC 暂缓 DC→FC 补货计划，等 DC 先清
2.2 FC Stock exp < DC exp FC 留 / FC Stock→DC Bin 维持 FC 存量，加速 FC Stock 出货
3.1 FC Stock < DC < FC Bin DC 触发 FC Date Switch：Stock→Bin 内部倒仓，Bin→DC
3.2 FC Bin < DC < FC Stock DC 优先清 FC Bin，加速 FC Bin→DC
3.3 FC Stock < FC Bin < DC FC 无额外动作，FC 整体比 DC 旧，FC 优先消化
3.4 FC Bin < FC Stock < DC DC 加速 FC→DC，移出 FC 最旧批次
3.5 DC < FC Stock < FC Bin DC DC 最旧先消化，新货进 DC 补充后续库存
3.6 DC < FC Bin < FC Stock DC 同 3.5，DC 先出旧货，FC 不动

⚠️ 两种需要反向触发 Planning 的场景
触发条件Planning 动作
新货进了 FC Bin，但 新货 exp < FC 现有货 exp RESEQUENCE：将 FC 现有较新批次移到 Stock 缓冲，确保 FC Bin 保持 FEFO
新货最旧（新货 exp < DC exp）被推到 DC DC_PRIORITY_OUT：将 DC 此 SKU 标为最高出库优先级，FIFO 最前处理
